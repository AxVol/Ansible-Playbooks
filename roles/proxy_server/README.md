Название роли
=========
## proxy_server

Данная роль предназначена для установки squid прокси на сервер. 
Протестировано на ubuntu 18, 24

Переменные роли
--------------
### Прописывается в vars/main.yml
- `proxy_port:` Порт на котором работает прокси, по умолчанию 5090
- `ip_for_web_log:` IP адресс с которого можно подключиться к лог аналайзеру установленном на этом сервере (правило для iptables)
- `ssh_ips:` Список IP адрессов которые могут подключаться к серверу по ssh (правило для iptables)
- `white_list:` Белый список (и список yaml = )) для сервисов, которые нужно открыть, если они попадают в запрещающие списки по подсетям (acl для squid)
- `block_subnets:` Список подсетей с которых запрещено подключаться к прокси (acl для squid)
- `black_list:` Черный список сервисов к которым запрещенно подключаться (acls для squid)

Содержание files
--------------
- sarm.conf - Конфиг лог аналайзера 
- squidarm.conf - Конфиг апача для лог аналайзера
- squidarm.list - deb source list для скачивания лог аналайзера

Содержание templates
--------------
- squid.conf.j2 - Конфигурация squid
acls/
- black_list.j2 - черный список Squid
- block_subnets.j2 - Заблокированые подсети Squid
- white_local_list.j2 - Белый список Squid

Содержание tasks
--------------
- apache.yml - Устанавливает апач и включает в нем необходимые модули
- squid.yml - Устанавливает и настраивает squid (конфиг и acls)
- logs_analyzer.yml - Устанавливает и настраивает лог аналайзер
- iptables.yml - Настраивает правила для фаерволла

Содержание handlers
--------------
- restart apache - Перезапускает apache
- restart squid - Перезапускает squid
