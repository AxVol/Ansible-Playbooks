Название роли
=========
## docker

Устанавливает в систему docker в базовой конфигурации с включенной ротацией логов до 5 файлов и 50mb. Установка протестирована на Debian-based, RedHat-based и Astra Linux. Установка производиться в online режиме, offline не поддерживается.

Переменные роли
--------------

### Переменные в defaults/main.yml 
- `docker_user:` - Логин пользователя под чьим именем ansible работает в системе чтобы добавить его в группу docker для будущего управления контейнерами

Содержание files
--------------
- daemon.json - Настройка docker, в базовом варианте настроено логирование с ротацией логов.

Содержание handlers
--------------
- restart docker - Перезапускает docker демона

Содержание tasks
--------------
Реализовано определеине ОС хоста в рантайме, из-за чего запускаются только определенные таски под OC.

- install/ - Установка докера в зависимости от ОС
- docker_conf.yml - Конфигурация docker и daemon.json файла
