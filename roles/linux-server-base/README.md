Название роли
=========
## linux-server-base

Данная роль предназначена для базовой раскатки Linux сервера в минимальной комплектации с базовыми утилитами, создания пользователей с админ правами и блокировки рута по ssh, настройка ntp  и установка кастомных сертификатов.
Так же реализована блокировка входа по ssh по логину паролю, вместо этого установка входа по ssh ключам

Поддерживается установка на RedHat-based и Debian-based, в том числе Astra Linux.

Переменные роли
--------------
### Прописывается в inventory хоста
- `admins:` - Список пользователей с админ правами, которых нужно добавить на хосте. У списка admins должно быть 3 переменных: name, password, key_path (может быть пустой, если перменная `ssh_keys` указана как false). Пример:
```yml
admins:
  - name: AxVol
    password: 123
    key_path: /home/key
```
- `ssh_keys:` - true/false, по умолчанию false. Определяет нужно ли устанавливать вход исключительно по ssh ключам.
### Прописывается в vars/
Переменные построены по типу определения ОС в рантайме и подключения конкретного файла vars чтобы не засорять контекст выполнения. Поэтому ниже перечислены перменные которые едины для всех дистрибутивов, если переменная уникальная - это будет указано

Chrony/
- `chrony_service_name:` - имя службы chrony, по умолчанию chrony (chronyd для RedHat)
- `chrony_conf_dest:` - Путь к конфигу chrony, по умолчанию /etc/chrony
- `chrony_driftfile:` - Файл дрейфа для точного вычисления времени на хосте из-за погрешности железа, по умолчанию /var/lib/chrony/chrony.drift (RedHat /var/lib/chrony/drift)
- `chrony_keyfile:` - ключи защиты chrony при взаимодействии по сети, по умолчанию /etc/chrony/chrony.keys (RedHat /etc/chrony.keys)

Packages/
- `ssh_name:` - Название службы ssh под конкретный дисрибутив
- `tools:` - Список пакетов которые необходимо установить для дистрибутива

Users/Groups/
- `admin_groups:` - Группы в которые необходимо добавить админский пользователей в конкретном дистрибутиве

### Прописывается в defaults/main.yml
- `chrony_servers:` - Список chrony серверов

Содержание files
--------------
- certs/ - Директория из которой в систему будут установлены сертификаты в доверненные и корневые.
- ssh_conf/
   - 99-root-block.conf - базовая конфигурация + блокировка рута
   - 98-ssh-keys.conf - блокировка входа по паролю и активация ssh ключей

Содержание templates
--------------
- chrony.conf.j2 - Конфиг файл для chrony
- sources.list.j2 - source листы для астры

Содержание tasks
--------------
- Users/admin-users-creation.yml - создаёт учётные записи администраторов, особенность заключается в том, что указанный пароль в inventory является первичным(служебный) для входа, после первой авторизации система затребует сменить пароль.
- Packages/{{ ansible_facts['os_family'] }}.yml - Устанавливает базовый набор пакетов, специфичный для данного семейства ОС, из переменной `tools`
- SSH/ssh-hardening.yml - Настраивает ssh. Отключает root, и включает вход исключительно по ключам ssh в зависимости от переменой `ssh_keys`.
- Users/pdp-policy-astraLinux.yml - выполняется только для семейства Astra Linux, настраивает мандатную политику доступа
- NTP/chrony-init.yml - Отключает сторонее управление ntp, устанавливает и настраивает chrony.
- CA/certs-deploy.yml - Устанавливает сертификаты из директории `certs/`

Содержание handlers
--------------
- reload-sshd - Перезапускает ssh
- restart chrony - Перезапускает chrony
- update ca {dist} - Устанавливает серты под соответствующий дистрибутив.
